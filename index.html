What Is Machine Learning?

Machine learning is a way of building software that improves at a task by learning from data, rather than following rules a programmer wrote by hand. Instead of coding "if X then Y" for every case, you show the program many examples and let it find the pattern connecting the input to the output.

The result is a model: a function, fitted to data, that can make a prediction or decision on new examples it hasn't seen before.

Supervised, Unsupervised, and Reinforcement Learning

Supervised learning trains on labeled examples — each input comes with the correct answer attached, such as an email marked "spam" or "not spam." The model learns to map inputs to those known outputs.

Unsupervised learning works on unlabeled data. There's no correct answer given; instead, the model finds structure on its own, such as grouping similar customers together (clustering) or identifying which features matter most.

Reinforcement learning learns by trial and error inside an environment, receiving rewards or penalties for its actions. Rather than learning from a fixed dataset, it learns a strategy by acting, observing the outcome, and adjusting — the approach behind game-playing agents and robotics control.

The Train/Test Split

A model that's only ever evaluated on the data it was trained on will look better than it really is — it can memorize answers instead of learning general patterns. To catch this, the available data is split: most of it (the training set) is used to fit the model, and a held-out portion (the test set) is used only to measure how well it performs on examples it never saw during training.

A common split is 80% training, 20% testing, though the right ratio depends on how much data is available.

Overfitting

Overfitting happens when a model learns the training data too well — including its noise and quirks — rather than the general pattern underneath. An overfit model scores extremely well on training data but performs poorly on new, unseen data, because it memorized specifics instead of learning something that generalizes.

The train/test split exists specifically to detect this: a big gap between training accuracy and test accuracy is the classic sign of overfitting.

Common Algorithms

A few algorithms show up across most introductions to the field:

  • Linear regression — predicts a continuous number by fitting a straight-line relationship between inputs and output.
  • Logistic regression — despite the name, used for classification: predicting one of a fixed set of categories.
  • Decision trees — make predictions by asking a sequence of yes/no questions about the input, learned from the data.
  • k-means clustering — an unsupervised method that groups data points into a chosen number of clusters based on similarity.
  • Neural networks — layers of simple connected units that combine to approximate complex, non-linear relationships between inputs and outputs.
